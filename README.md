# New outlet opening approval format dashboard

This package is ready for GitHub Pages and works entirely in the browser.

## Publish

1. Extract the ZIP.
2. In the `aftabz-lab.github.io` repository, create a folder named `new-outlet-opening-approval-format-dashboard`.
3. Upload all extracted files and folders into that folder. Keep `index.html`, `app.js`, `styles.css` and the `assets` folder together.
4. Commit the files to the branch used by GitHub Pages.
5. Open `https://aftabz-lab.github.io/new-outlet-opening-approval-format-dashboard/` after deployment finishes.

## Use

1. Click **Select File from Device**.
2. Select the monthly `.xlsx` incentive workbook. The filename may be different each month.
3. Confirm that Appendix A and Appendix B totals match.
4. Click **New outlet opening approval Generate**.

The dashboard derives the month from the workbook, creates the approval note and both appendices, adds the default Aftab and Saiful signatures, and downloads the completed PDF. The workbook is processed locally and is not uploaded by this dashboard.
